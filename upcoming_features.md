# Upcoming Features & Roadmap

This document tracks features that have been discussed and approved for future development, but are not part of the current implementation cycle.

### Core Form Elements
- **File Upload:** Allow respondents to upload images, PDFs, and documents as part of their response.
- **Time / DateTime:** Extended date pickers to capture specific hours and minutes (critical for incident reports).
- **Phone Number Validation:** Built-in regex validation for international phone number formats.

### Advanced Form Architecture
- **Reusable Linked Modules (Master Sets):** A centralized library of standard sections (e.g., "Employee Details"). Forms will link to this master module so that updating the master instantly updates all forms using it.
- **Media Integration:** Ability to insert standalone image or video blocks between questions, and attach images to multiple-choice options.
- **Quiz Mode:** A dedicated mode to assign correct answers, set point values, and automatically grade submissions.

### Analytics & Reporting
- **Calculated / Read-Only Fields:** Fields that automatically execute math or logic based on other inputs, specifically designed to aid in generating complex reports.
- **Cumulative Data Toggle:** An option per question to display data alongside its cumulative/historical data points in the analytics view.
